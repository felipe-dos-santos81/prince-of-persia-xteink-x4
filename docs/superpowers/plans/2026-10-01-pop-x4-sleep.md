# Sleep Screen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** After 30 s with no button pressed, the X4 shows the game's title screen with a "Press power to wake" hint and enters deep sleep; the power button wakes it and the demo starts over.

**Architecture:** A plain-C inactivity timer (`firmware/src/idle.c`, tested on the Mac) is fed once per emulated frame by a small button reader (`firmware/src/input.cpp`). The emulator task snapshots emulated frame 1200 (the title screen) and, when the timer expires and no USB host is connected, hands over to the display task, which shows the snapshot with one full refresh, powers the panel controller off and enters deep sleep with a wake on the power button.

**Tech Stack:** C99 and C++ (Arduino core 3.3.7 on ESP32-C3, ESP-IDF 5.5 `esp_sleep.h`), GNU make, PlatformIO.

**Spec:** `docs/superpowers/specs/2026-10-01-pop-x4-sleep-design.md`. It extends `docs/superpowers/specs/2026-10-01-pop-xteink-x4-design.md`; read both.

**How this plan was checked:** all code below was built in a throwaway worktree. On the Mac, `make test` prints nine `ok` lines. The firmware links (static RAM 219,704 bytes). On the X4, plugged into the Mac, the boot log showed `sleep: postponed while USB is connected` once, about 30 s after boot, and a probe read 4095 on both button ladders with nothing pressed (the threshold is 3,800). Planning also found an existing bug: plugged into a USB host that is not reading the serial port, the firmware stopped emulating within minutes (the first log line after 5 unread minutes showed `cps=53`); with the Task 1 fix the same test shows normal speed. Not checked yet: pressed-button readings, the sleep screen, deep sleep and wake; Task 3 checks them with your human partner.

## Global Constraints

- Work on branch `pop-emulator`. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- `core/` stays untouched: the firmware uses it only through `core/machine.h`.
- Host code compiles with `-std=c99 -Wall -Wextra` and produces no warnings.
- Buttons: front ladder on GPIO1, side ladder on GPIO2 (ADC, 0–4095; at or below 3,800 = a button is down); power button on GPIO3, active low with the internal pull-up.
- Sleep after 30,000 ms with no button pressed. Snapshot emulated frame 1200. `SLEEP_ON_USB` defaults to 0.
- A halted machine never sleeps.
- **Anything that writes to the device needs your human partner's explicit go-ahead first.** Flash with `make flash fast=1` (the device runs the fast waveform by their choice); `pio run -t upload` does not work on this Mac.

## Review Focus

1. **The power button is still held when the device goes to sleep.** It must not wake straight back up. Pinned by the release wait in `enter_deep_sleep()` and Task 3, Step 9.
2. **The device is plugged into the Mac with nothing reading the serial port.** The demo must keep running (it froze before Task 1), stay awake and flashable, and say once why it is not sleeping. Pinned in Task 1, Step 4 and Task 3, Step 6.
3. **A button press just before 30 s.** It must postpone sleep by a full 30 s. Pinned by `test_activity_restarts_the_count` (Task 2) and Task 3, Step 7.
4. **The machine halts.** The halt screen must stay; no sleep. Pinned in Task 3, Step 10.
5. **`millis()` wraps after 49.7 days.** The timer must keep working. Pinned by `test_survives_millis_wrap` (Task 2).

### Task 1: Keep logging from freezing the emulator

**Files:**
- Create: `tools/x4log.py`
- Modify: `firmware/src/main.cpp`, `docs/superpowers/specs/2026-10-01-pop-xteink-x4-design.md`

**Interfaces:**
- Consumes: nothing new.
- Produces: `tools/x4log.py N`: resets the X4 and prints its serial log with timestamps for N seconds. Used by Task 3.

The bug: `setup()` calls `Serial.setTxTimeoutMs(0)`. In Arduino core 3.3.7, `HWCDC::write()` (`cores/esp32/HWCDC.cpp`, around line 456) waits for a host that is connected but not reading by counting `tries` down from the timeout, one per millisecond, and gives up at zero. With a timeout of 0 the first decrement wraps to 4,294,967,295, so it never gives up: once the transmit buffer is full, every log line blocks until someone opens the port, and the emulator task stops with it. With 1 ms it gives up after one stalled millisecond, marks the host as not listening, and later writes return at once.

- [ ] **Step 1: Write the log reader**

Write `tools/x4log.py`, a serial reader that resets the X4 the way `esptool` does (an RTS pulse) and prints its log, with timestamps, for the number of seconds given:

import serial

s = serial.Serial(port, 115200, timeout=1)
s.setDTR(False); s.setRTS(True); time.sleep(0.1); s.setRTS(False); s.close()
time.sleep(0.5)
for _ in range(50):
    try:
        s = serial.Serial(port, 115200, timeout=1)
        break
    except serial.SerialException:
        time.sleep(0.1)
start = time.time()
while time.time() - start < float(sys.argv[1]):
    line = s.readline().decode(errors="replace").strip()
    if line:
        print("%5.1f %s" % (time.time() - start, line), flush=True)
```

#include "idle.h"
#include "test.h"

#define TIMEOUT 30000u

static void test_not_expired_before_timeout(void)
{
    idle_timer_t t;

    idle_reset(&t, 1000u, TIMEOUT);
    CHECK(!idle_update(&t, 1000u + TIMEOUT - 1u, false));
}

static void test_expires_at_timeout(void)
{
    idle_timer_t t;

    idle_reset(&t, 1000u, TIMEOUT);
    CHECK(idle_update(&t, 1000u + TIMEOUT, false));
    CHECK(idle_update(&t, 1000u + TIMEOUT + 5000u, false));
}

static void test_activity_restarts_the_count(void)
{
    idle_timer_t t;

    idle_reset(&t, 0u, TIMEOUT);
    CHECK(!idle_update(&t, 20000u, true));
    CHECK(!idle_update(&t, 20000u + TIMEOUT - 1u, false));
    CHECK(idle_update(&t, 20000u + TIMEOUT, false));
}

static void test_activity_after_expiry_restarts_the_count(void)
{
    idle_timer_t t;

    idle_reset(&t, 0u, TIMEOUT);
    CHECK(idle_update(&t, TIMEOUT, false));
    CHECK(!idle_update(&t, TIMEOUT + 10u, true));
    CHECK(!idle_update(&t, TIMEOUT + 20u, false));
}

static void test_survives_millis_wrap(void)
{
    idle_timer_t t;
    uint32_t start = 0xFFFFF000u; /* 4,096 ms before millis() wraps */

    idle_reset(&t, start, TIMEOUT);
    CHECK(!idle_update(&t, start + TIMEOUT - 1u, false));
    CHECK(idle_update(&t, start + TIMEOUT, false));
}

int main(void)
{
    test_not_expired_before_timeout();
    test_expires_at_timeout();
    test_activity_restarts_the_count();
    test_activity_after_expiry_restarts_the_count();
    test_survives_millis_wrap();
    return TEST_RESULT();
}
```

- [ ] **Step 4: Write the timer**

`firmware/src/idle.h`:

```c
#ifndef IDLE_H
#define IDLE_H

#include <stdbool.h>
#include <stdint.h>

#ifdef __cplusplus
extern "C" {
#endif

/* Inactivity timer. Times are millis() values; only differences are used, so
   the 49-day wrap of millis() does not matter. */
typedef struct {
    uint32_t last_active_ms;
    uint32_t timeout_ms;
} idle_timer_t;

/* Start counting from now_ms (which counts as activity). */
void idle_reset(idle_timer_t *t, uint32_t now_ms, uint32_t timeout_ms);

/* Feed one sample. Returns true once timeout_ms has passed since the last
   sample with active set; an active sample restarts the count. */
bool idle_update(idle_timer_t *t, uint32_t now_ms, bool active);

#ifdef __cplusplus
}
#endif

#endif
```

`firmware/src/idle.c`:

```c
#include "idle.h"

void idle_reset(idle_timer_t *t, uint32_t now_ms, uint32_t timeout_ms)
{
    t->last_active_ms = now_ms;
    t->timeout_ms = timeout_ms;
}

bool idle_update(idle_timer_t *t, uint32_t now_ms, bool active)
{
    if (active) {
        t->last_active_ms = now_ms;
        return false;
    }
    return (uint32_t)(now_ms - t->last_active_ms) >= t->timeout_ms;
}
```

/* Show the sleep screen and power down until the power button is pressed.
   Waking is a reset: setup() runs again. Does not return. */
static void enter_deep_sleep(void)
{
    display_show_sleep(have_sleep_picture ? sleep_picture : picture);

    /* A held button would wake the chip straight away. */
    while (input_power_pressed()) {
        delay(10);
    }
    delay(50);
    esp_deep_sleep_enable_gpio_wakeup(1ULL << BUTTON_POWER_PIN, ESP_GPIO_WAKEUP_GPIO_LOW);
    esp_deep_sleep_start();
}

/* Once IDLE_SLEEP_MS passes with no button pressed, hand over to the display
   task to sleep. While a USB host is connected, stay awake unless
   SLEEP_ON_USB is set, so the device can still be flashed and monitored. */
static void check_idle(void)
{
    static bool postponed_logged;

    if (!idle_update(&idle, millis(), input_any_pressed())) {
        return;
    }
    if (!SLEEP_ON_USB && HWCDC::isPlugged()) {
        if (!postponed_logged) {
            Serial.println("sleep: postponed while USB is connected");
            postponed_logged = true;
        }
        return;
    }
    Serial.printf("sleep: idle for %u s\n", (unsigned)(IDLE_SLEEP_MS / 1000));
    sleeping = true;
    xSemaphoreGive(frame_ready); /* wake the display task to sleep */
}
