# AGENTS.md

Standalone ESP32-C3 firmware that runs Jordan Mechner's Apple II Prince of
Persia (title sequence + attract demo) on an Xteink X4 e-ink panel. A portable
6502/Apple IIe emulator lives in `core/` and is shared by the host runners
(`host/`) and the Arduino firmware (`firmware/src/`).

## Build and test order

- `make game` builds the 3.5" disk image from source in Docker (`linux/386`),
  cloning Adam Green's fork at a pinned commit and checking the image SHA-256.
  `make test`, `make run` and `make firmware` depend on
  `game/out/PrinceOfPersia_3.5.hdv` and build it on demand.
- `make test` runs nine hand-rolled test executables (no framework). Tests
  link only the sources they exercise; see the per-test rules in the Makefile.
- Single test: `make build/test_cpu && ./build/test_cpu tests/data/6502_functional_test.bin`.
  `test_boot` takes two args: `./build/test_boot game/out/PrinceOfPersia_3.5.hdv tests/golden.txt`.
  The Klaus test binary is fetched on demand by `tests/fetch_klaus.sh` (network,
  hash-checked).
- `make soak` runs the headless runner for 260,000 frames to exercise the
  32-bit cycle counter wrap.
- `make firmware [fast=1|halt=1|sleep_usb=1]` passes `-D` flags through
  `PLATFORMIO_BUILD_FLAGS`; a bare `cd firmware && pio run` ignores them.

## Architecture invariants

- `core/` must stay dependency-free C: no Arduino or SDL headers. `scale.c` and
  `idle.c` from `firmware/src/` are compiled into host tests, so they must stay
  Arduino-free too.
- The disk image is embedded with `.incbin` in `firmware/src/disk_image.S`,
  which PlatformIO does not track; the Makefile force-cleans when the image is
  newer. Never assume an incremental `pio run` picked up a rebuilt image.
- `board_build.flash_mode = dio` is required: the X4's flash cannot be read by
  the default QIO bootloader.
- `tests/golden.txt` hashes are tied to the pinned image SHA-256 in
  `game/build.sh`. Update them only when that image and the render path are
  unchanged.

## Device hazards

- `fast=1` (`FAST_LUT`) drives the panel outside its rated parameters and may
  permanently damage the display.
- `make flash` refuses to run without `backup/x4-flash-backup.bin`; `make backup`
  reads the whole 16 MB flash. `make restore` writes it back.
- Ports auto-detect as `/dev/cu.usbmodem*`; override with `port=...`.
  By default the firmware stays awake on USB; `sleep_usb=1` lets it sleep.
- `make monitor` for serial logs; `tools/x4log.py N` resets and timestamps the
  log (needs `pyserial`).

## Repo state

- `game/work/`, `game/out/`, `tests/data/` and `backup/` are gitignored: no game
  code, ROM or disk image is ever committed.
- `core/fake6502.inc` is generated by `tools/vendor_fake6502.py` (pinned
  upstream + NMOS decimal fixes); do not hand-edit it.
